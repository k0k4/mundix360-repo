Mundix Security 360 — canal de atualizações estáveis

Repositório APT assinado com o pacote mundix360 (somente versões estáveis publicadas em release). Projeto: github.com/k0k4/mundix360.

Configurar o canal num appliance

sudo /opt/mundix360/scripts/ops/mundix-upgrade.sh --setup-channel

ou manualmente:

sudo curl -fsSL https://k0k4.github.io/mundix360-repo/mundix-repo.gpg -o /usr/share/keyrings/mundix-repo.gpg
echo "deb [signed-by=/usr/share/keyrings/mundix-repo.gpg] https://k0k4.github.io/mundix360-repo stable main" | sudo tee /etc/apt/sources.list.d/mundix360.list
sudo apt update

Verificar / atualizar

sudo /opt/mundix360/scripts/ops/mundix-upgrade.sh --check   # só verifica
sudo /opt/mundix360/scripts/ops/mundix-upgrade.sh           # aplica a estável mais nova

Pelo painel: Sistema → Atualizações → Verificar atualizações.
